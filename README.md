# ExamForge — Premium Exam Simulator

A serious, full-featured exam-performance operating system for JEE/NEET aspirants.

## 📦 What's Inside

### ⭐ The Main App
- **`examforge.html`** — Single-file functional app. Just open in any browser.
  Includes: auth, dashboard, test builder, question bank, exam engine, mistake
  analysis, reflection, history, analytics, AI Coach, Smart Insights, Exam
  Readiness Score, Study Plan, Flashcards (SR), Focus Mode (Pomodoro),
  command palette (⌘K), light/dark theme, full data export/import.

### 🧱 The React Scaffold (for future hosting / collaboration)
- **`examforge/`** — Vite + React + TypeScript + Tailwind project skeleton
  with the same design tokens and architecture from Phases 1–3.
  Run: `cd examforge && npm install && npm run dev`

### 🎨 Design Previews (static, for reference)
- **`preview.html`** — Phase 1 landing/dashboard design system
- **`preview-phase2.html`** — Auth screens preview
- **`preview-phase3.html`** — Dashboard with stats preview

## 🚀 Quick Start

**Just want to use it?**
1. Unzip
2. Double-click `examforge.html`
3. "Try as Guest" or sign up — your data lives in your browser

**Want to develop/host the React version?**
```bash
cd examforge
npm install
npm run dev
```

## ⌨️ Keyboard Shortcuts (single-file app)
- `⌘K / Ctrl+K` — Command palette
- `⌘/  / Ctrl+/` — AI Coach
- `⌘D / Ctrl+D` — Dashboard
- `⌘I / Ctrl+I` — Smart Insights
- `⌘B / Ctrl+B` — Question Bank
- `⌘F / Ctrl+F` — Focus Mode
- `ESC` — Exit Focus Mode

## 💾 Your Data
Everything is stored locally in your browser's localStorage. Use Settings → Export to back up. Nothing leaves your device.
